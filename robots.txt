# Dieses Verzeichnis bleibt bewusst crawlbar.
#
# Klingt widerspruechlich, ist aber der einzige Weg, der funktioniert:
# Das "noindex" steht im <head> von index.html. Eine Suchmaschine kann es
# nur befolgen, wenn sie die Seite abrufen darf. Ein "Disallow: /" wuerde
# den Abruf verhindern, das noindex damit unsichtbar machen, und die nackte
# Adresse koennte trotzdem im Index landen, sobald irgendwo ein Link darauf
# zeigt. Crawlen erlauben, Indexieren verbieten ist die richtige Reihenfolge.
User-agent: *
Allow: /
